# PastReads for KOReader

[PastReads](https://www.pastreads.com/) is a place to collect, search, and revisit your reading highlights. This plugin adds **PastReads** as an export target in KOReader’s built-in **Export Highlights** feature, so you can send highlights from your device over Wi‑Fi.

For the full walkthrough (token setup, exporting, troubleshooting), see the [KOReader docs](https://www.pastreads.com/docs/import-highlights/koreader).

## Installation

1. Download the plugin (can also be downloaded from [pastreads.com/koreader/download](https://www.pastreads.com/koreader/download))
2. Unzip the archive and copy `provider-pastreads.koplugin` into KOReader’s `plugins/` folder.
3. Restart KOReader.

Then generate an access token in PastReads (**Import** → **KOReader**), paste it under **Export highlights** → **Choose formats and services** → **PastReads**, and enable **Export to PastReads**.

## Updates

In the PastReads exporter settings in KOReader, tap **Check for updates**. If a newer version is available, the plugin installs it for you—restart KOReader afterward to finish.
